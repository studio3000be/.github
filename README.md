# .github

Organisation-level files for [studio3000](https://github.com/studio3000be).

- [`profile/README.md`](profile/README.md) renders as the public org page at [github.com/studio3000be](https://github.com/studio3000be).
- [`profile/assets/`](profile/assets) holds the logo variants used by that page.

Default community health files (`CONTRIBUTING.md`, `SECURITY.md`, issue and PR templates) can be added here later and will apply to every repo in the org that does not define its own.
